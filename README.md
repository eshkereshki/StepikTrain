Проверка кнопки добавления в корзину

Автотест для проверки отображения кнопки «Добавить в корзину» для различных языковых локализаций интерфейса.

Установка зависимостей

pip install pytest selenium


Запуск автотеста

Запуск выполняется командой pytest с обязательным указанием параметра --language:

# Французский язык
pytest -s -v --language=fr test_items.py

# Испанский язык
pytest -s -v --language=es test_items.py

# Русский язык
pytest -s -v --language=ru test_items.py

# Английский язык (по умолчанию)
pytest -s -v test_items.py


Файлы проекта

conftest.py — конфигурация фикстуры браузера Chrome с передачей параметра языка --language.

test_items.py — сценарий открытия страницы товара и проверки наличия кнопки добавления в корзину.
